# RiceNote Theme API v1

> 面向主题作者。你只需要 **HTML + CSS +（可选）Nunjucks 语法**，不需要 npm、打包器或 Node.js。

## 1. 主题包结构

```
themes/minimal/
├── theme.json              # 必需：主题清单
├── screenshot.png          # 可选：后台预览图
├── templates/
│   ├── layout.njk          # 布局（被其他模板 extends）
│   ├── index.njk           # 首页
│   ├── post.njk            # 文章详情
│   ├── archive.njk         # 归档 / 分类列表
│   ├── search.njk          # 搜索
│   ├── 404.njk             # 404
│   └── partials/
│       ├── header.njk
│       ├── footer.njk
│       └── pagination.njk
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── images/
```

安装方式：后台「外观 → 主题 → 上传 ZIP」，或直接把目录放到 `THEMES_DIR` 下。

## 2. theme.json 契约

由 `packages/shared/manifests/theme.schema.json` 校验。

```json
{
  "schemaVersion": 1,
  "id": "rice.minimal",
  "name": "Minimal",
  "version": "1.0.0",
  "apiVersion": "^1.0.0",
  "engine": "nunjucks",
  "screenshot": "./screenshot.png",
  "templates": {
    "home": "index.njk",
    "post": "post.njk",
    "page": "page.njk",
    "archive": "archive.njk",
    "search": "search.njk",
    "404": "404.njk"
  },
  "pageTemplates": {
    "default": { "template": "page.njk", "label": { "zh-CN": "标准页面", "en": "Standard page" } },
    "plain": {
      "template": "page-plain.njk",
      "label": { "zh-CN": "落地页（无标题）", "en": "Landing page (no heading)" },
      "description": { "zh-CN": "适合标题已写在正文中的推广页", "en": "For pages whose title lives in the content" }
    }
  },
  "requires": { "content.posts@1": "^1.0.0" },
  "settings": {
    "appearance": {
      "label": "外观",
      "fields": {
        "accentColor": { "type": "color", "label": "强调色", "default": "#89A9C7" },
        "showSidebar": { "type": "boolean", "label": "显示侧边栏", "default": true },
        "layoutWidth": { "type": "number", "label": "内容宽度(px)", "default": 960, "min": 640, "max": 1440 },
        "fontFamily": {
          "type": "select",
          "label": "字体",
          "default": "system",
          "options": [
            { "label": "系统", "value": "system" },
            { "label": "衬线", "value": "serif" }
          ]
        }
      }
    },
    "footer": {
      "label": "页脚",
      "fields": {
        "footerText": { "type": "text", "label": "页脚文字", "default": "Powered by RiceNote", "maxLength": 160 }
      }
    }
  }
}
```

### 模板映射

`templates` 的键是**页面类型（kind）**，由提供页面的插件决定。Core 内置约定的 kind：

| kind | 场景 | 提供者 | 是否必需 |
| --- | --- | --- | --- |
| `home` | 首页 | `rice.posts` | 必需 |
| `post` | 文章详情 | `rice.posts` | 建议 |
| `page` | 自定义页面（`/page/:slug`） | `rice.pages` | 可选 |
| `archive` | 归档 / 分类 / 标签列表 | `rice.posts` | 可选 |
| `search` | 搜索结果 | `rice.search` | 可选 |
| `404` | 未找到 | Core（插件可返回 `kind: '404'`） | 建议 |

缺少某个 kind 的模板不会白屏：渲染器会按第 8 节的回退链降级。
`pageTemplates` 是可选的**可供内容选择的模板清单**，详见第 12 节。

### 设置字段类型白名单

| 类型 | 说明 | 附加约束 |
| --- | --- | --- |
| `text` | 单行文本 | `maxLength` |
| `textarea` | 多行文本 | `maxLength` |
| `color` | 颜色 | 自动经 `css_color` 白名单校验 |
| `boolean` | 开关 | `default` 必须为布尔 |
| `number` | 数值 | `min` / `max` |
| `select` | 下拉 | 必须提供 `options` |
| `image` | 图片 | 打开媒体库，保存 Media ID 或受管相对路径 |
| `url` | 链接 | 必须以 `http://` 或 `https://` 开头 |
| `stringList` | 多行文本，每行一项 | `maxItems`（默认 200）、`maxLength`（单项长度）；值为 `string[]`，提交时也接受按行分隔的字符串 |

> `image` 类型**不允许**保存任意服务器文件路径，这是硬性安全约束。

### 多语言文案（M4 新增）

`label` / `description` / `placeholder` / `options[].label` 均支持两种写法：

```json
{
  "label": { "zh-CN": "主色", "en": "Accent" },
  "options": [
    { "label": { "zh-CN": "细体", "en": "Light" }, "value": "300" }
  ]
}
```

- 字符串写法等价于"只声明一种语言"，未声明多语言的主题行为完全不变；
- 解析顺序：**精确语言标签 → 基础语言（`zh-CN` → `zh`）→ `en` → 首个非空值**；
- 解析发生在服务端（`resolveLocalizedText()`），后台拿到的 DTO 已是字符串，
  因此主题设置表单不需要处理多语言。

## 3. 模板上下文

| 变量 | 可用页面 | 说明 |
| --- | --- | --- |
| `site` | 全部 | `site.title` / `site.description` / `site.url` / `site.language` / **`site.logoUrl`** / **`site.faviconUrl`** / **`site.icpText`** / **`site.icpUrl`**（后四项未设置时为空字符串，即"变量存在但无值"） |
| `page` | 全部 | `page.kind` / `page.title` / `page.canonicalUrl`，以及**插件 `data` 的全部键**（被合并进 `page`，如 `page.post`） |
| `theme` | 全部 | `theme.id` / `theme.name` / `theme.version` / `theme.settings.*` |
| `viewer` | 可选 | 仅暴露 `{ id, name }`（已登录时才有） |
| `post` | 文章页 | `post.title` / `post.html` / `post.terms` / `post.url` / `post.template?` |
| `posts` | 列表页 | `posts.items` / `posts.total` / `posts.page` / `posts.totalPages` |
| **`content`** | 自定义页面（`kind = 'page'`） | **`content.title`** / **`content.html`** / **`content.slug`** / **`content.url`** / **`content.updatedAt`** / **`content.template?`** |
| `pagination` | 列表页 | `pagination.hasPrev` / `hasNext` / `prevUrl` / `nextUrl` |
| `seoDescription` | 插件自行提供 | 插件在 `data` 里给出的描述（`rice.posts` 与 `rice.pages` 都会提供），供 `{% block description %}` 使用 |

> `theme.settings` 是**扁平化字段名 → 值**的映射，字段名在整个主题范围内必须唯一。
>
> 自定义页面的内容变量刻意命名为 `content` 而不是 `page`：`page` 已被 Core 用作页面元信息
> （kind / title / canonicalUrl），复用会让模板难以阅读。
>
> **`site` 是实时取值**：后台「系统设置」里改了站点标题/描述/地址/Logo/备案后立即生效，
> 不需要重启，也不需要主题做任何事。

## 4. Helper

| Helper | 用法 | 说明 |
| --- | --- | --- |
| `theme_asset` | `{{ theme_asset('css/style.css') }}` | 输出带指纹（`?v=主题版本`）的静态资源 URL |
| `url` | `{{ url('post.show', { slug: post.slug }) }}` | 基于已注册命名路由生成 URL |
| `slot` | `{{ slot('post.comments', { postId: post.id }) }}` | 输出该插槽的安全 HTML 片段 |
| `has_feature` | `{% if has_feature('comments') %}` | 判断能力当前是否实际启用 |
| `site_url` | `{{ site_url('/sitemap.xml') }}` | 把站点相对路径拼成绝对地址（用于 canonical / 分享链接） |

`url()` 的降级行为（M4 新增）：当路由名未注册时，它**不会抛错**，
而是输出 `#` 并在服务端日志中告警一次（同一路由名只告警一次）。
这样主题即使用到可选插件提供的路由（例如 `search` 被禁用时的 `url('search')`），
也只会得到一个失效链接，而不会让整页渲染失败。

> 更严谨的做法是用 `has_feature('search')` 把关是否输出该链接；
> 两套内置主题都采用这种方式，因此禁用 search 插件后搜索入口整体不渲染。

## 5. 过滤器

| 过滤器 | 用法 | 说明 |
| --- | --- | --- |
| `css_color` | `{{ theme.settings.accentColor \| css_color }}` | 严格白名单校验 CSS 颜色，非法值回退 `transparent` |
| `date` | `{{ post.publishedAt \| date('YYYY-MM-DD') }}` | 支持 `YYYY/MM/DD/HH/mm/ss`；非法日期返回空字符串 |
| `excerpt` | `{{ post.html \| excerpt(120) }}` | 剥离 HTML、压缩空白后截断 |
| `number` | `{{ count \| number }}` | 非法数字回退为 0，避免输出 `NaN` |
| `json` | `{{ schema \| json }}` | 输出安全的 JSON 字面量（Core 内置，供结构化数据使用） |

## 6. 标准 Slot

| Slot | 位置 |
| --- | --- |
| `head.end` | `</head>` 之前 |
| `body.start` / `body.end` | `<body>` 起始 / 结束 |
| `header.navigation` | 主导航区域 |
| `sidebar.widgets` | 侧边栏 |
| `post.beforeContent` / `post.afterContent` | 正文前后 |
| `post.comments` | 评论区 |
| `footer.widgets` | 页脚 |

Slot 内组件由插件提供，按 `priority` 排序；单个组件异常会被隔离并降级为空片段，
**不会**导致整页渲染失败。插件被禁用时对应 Slot 自动为空。

### 容器由主题提供，内容由插件提供

标准约定：**主题负责外层容器与标题，插件只输出"区块内容"**。以评论区为例：

```html
{# 主题：容器 + 标题 + 能力判断 #}
{% if has_feature('comments') %}
  <section class="rn-comments">
    <h2>评论</h2>
    {{ slot('post.comments', { post: post }) }}
  </section>
{% endif %}
```

`rice.comments` 只输出计数、列表、分页与提交表单，不输出 `<section>` / `<h2>`，
因此不会与主题的容器重复。Slot 可用的数据键：

| Slot | 建议传入 | 插件可读取的上下文 |
| --- | --- | --- |
| `post.comments` | `{ post: post }`（也兼容 `{ postId: post.id }`） | `context.data.post`、`context.request.query` |
| `post.beforeContent` / `post.afterContent` | `{ postId: post.id }` | 页面 `data` 会被自动合并，因此 `context.data.post` 同样可用 |
| `head.end` | 无 | `context.kind`、`context.data`、`context.request`（用于生成 canonical / og:url） |

### 插件自带类名

Slot 片段使用的类名属于**插件约定**（例如评论区的 `rn-comments__*`、`rn-comment*`、`rn-field*`）。
主题要么按这些类名配色（两套内置主题都提供了对应样式），要么接受默认的朴素外观——
内容始终可读，不会被样式缺失破坏。

`post.comments` 支持无 JavaScript 提交：表单带 `action="/comments/submit"`，
服务端会 302 回到文章页并附上 `?comment=<结果>`，Slot 据此渲染提示条。
两套内置主题的脚本会拦截提交改为就地反馈，属于增强而非必需。

## 7. 完整模板示例

```html
{# templates/layout.njk #}
<!doctype html>
<html lang="{{ site.language }}">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>{% block title %}{{ page.title }} · {{ site.title }}{% endblock %}</title>
  <link rel="stylesheet" href="{{ theme_asset('css/style.css') }}">
  {{ slot('head.end') }}
</head>
<body style="--accent: {{ theme.settings.accentColor | css_color }}; --width: {{ theme.settings.layoutWidth | number(960) }}px">
  <header class="site-header">
    <a href="{{ url('home') }}">{{ site.title }}</a>
    {{ slot('header.navigation') }}
  </header>

  <main>{% block content %}{% endblock %}</main>

  <footer class="site-footer">
    <p>{{ theme.settings.footerText }}</p>
    {{ slot('footer.widgets') }}
    {{ slot('body.end') }}
  </footer>
</body>
</html>
```

```html
{# templates/post.njk #}
{% extends "layout.njk" %}

{% block content %}
<article class="post">
  <h1>{{ post.title }}</h1>
  <time datetime="{{ post.publishedAt }}">{{ post.publishedAt | date('YYYY年MM月DD日') }}</time>
  <ul class="terms">
    {% for term in post.terms %}<li><a href="{{ url('term.archive', { slug: term.slug }) }}">{{ term.name }}</a></li>{% endfor %}
  </ul>

  {{ slot('post.beforeContent', { postId: post.id }) }}
  <div class="post-body">{{ post.html }}</div>
  {{ slot('post.afterContent', { postId: post.id }) }}

  {% if has_feature('comments') %}{{ slot('post.comments', { postId: post.id }) }}{% endif %}
</article>
{% endblock %}
```

## 8. 模板回退链

```
主题声明的模板（如 post.njk）
  → 主题内的 fallback.njk（若存在）
  → Core 内置兼容模板
```

因此：缺少某个 kind 的模板不会导致白屏，而是降级渲染并记录告警。

## 9. 安全与限制

- **禁止**主题访问数据库或调用任意服务器端代码；
- **禁止**主题注册或修改 `/admin`、`/api` 核心路由；
- HTML 默认自动转义；文章正文由插件提供**已消毒**并标记为 `TrustedHtml` 的内容；
- 主题设置中的颜色必须经 `css_color` 过滤器输出，**不得**直接插入任意字符串；
- Nunjucks **不是安全沙箱**，只允许管理员安装受信任主题；
- ZIP 安装会校验解压大小限额、Zip Slip 路径穿越与符号链接，路径归一化后才落盘。

## 10. 设置的三层模型

```
effective = defaults + publishedOverrides                 // 公众站点
preview   = defaults + publishedOverrides + draftOverrides // 后台预览（iframe）
```

- 后台「保存并发布」会原子提交整组设置，并使用 `revision` 乐观锁；版本不一致返回 `409`。
- 「恢复默认」只影响草稿，发布需再次确认。
- 「导出」不会包含 `secret` / `token` / `password` / `key` 结尾的字段。

## 11. 版本兼容策略

- `apiVersion` 使用 semver 区间；`engine` 目前仅支持 `nunjucks`。
- 模板上下文与 helper 在 v1 内保持向后兼容；新增 helper 属于向前兼容变更。
- 主题通过 `requires` 声明依赖的插件能力；能力缺失时后台会给出降级提示，
  `has_feature()` 返回 `false`，Slot 自动为空。

## 12. 自定义页面与页面模板（1.1.0 新增）

自定义页面由 `rice.pages` 插件提供，地址形如 `/page/about`，页面类型为 `page`。

### 12.1 三件事

1. **提供一个默认页面模板**：`templates.page` 指向 `page.njk`（缺失时回退到 `fallback.njk`）；
2. **（可选）声明可选模板清单**：`pageTemplates`，让编辑者在后台为每个页面选择版式；
3. **在 `<head>` 里用上站点标识**（可选）：`site.logoUrl` / `site.faviconUrl`。

### 12.2 页面模板的写法

```html
{# templates/page.njk —— 默认页面模板 #}
{% extends "layout.njk" %}
{% block title %}{{ page.title }} · {{ site.title }}{% endblock %}
{% block description %}{{ seoDescription or site.description }}{% endblock %}
{% block content %}
<article class="page">
  <h1>{{ content.title }}</h1>
  {% if content.updatedAt %}
    <p class="meta">最后更新 {{ content.updatedAt | date('YYYY年MM月DD日') }}</p>
  {% endif %}
  <div class="prose">{{ content.html }}</div>
</article>
{% endblock %}
```

要点：

- `content` 只在 `kind = 'page'` 时存在；访问前请判空
  （例如 `{% if content and content.html %}`），这样即使 pages 插件被禁用、
  你仍保留着模板文件也不会报错；
- `content.html` 是**已消毒并标记为受信任**的 HTML，`{{ content.html }}` 直接输出即可；
  其余字段一律自动转义；
- `{% block description %}` 用 `seoDescription`（插件提供）兜底到 `site.description`。

### 12.3 `pageTemplates` 声明

`pageTemplates` 的键是**模板选项键**，值是模板文件与展示文案：

```json
"pageTemplates": {
  "default": { "template": "page.njk",        "label": { "zh-CN": "标准页面" } },
  "plain":   { "template": "page-plain.njk",  "label": { "zh-CN": "落地页（无标题）" },
               "description": { "zh-CN": "不输出标题，适合标题写在正文中的页面" } },
  "narrow":  { "template": "page-narrow.njk", "label": { "zh-CN": "阅读版式（窄栏）" } }
}
```

作者需要知道的四件事：

| 事项 | 说明 |
| --- | --- |
| 键是内容里保存的东西 | 页面（以及文章）保存的是**键**（如 `narrow`），不是文件名 —— 你以后可以随意重命名 `.njk` 文件而不影响已有内容 |
| 文件必须存在 | 主题加载时校验：`pageTemplates[*].template` 指向的文件不存在则该主题校验不通过（后台会显示具体缺失项） |
| 同时可用于文章 | 同一份清单会出现在文章编辑的「模板」下拉里（可对某个文章套用同一版式） |
| 键失效要能回退 | 换主题后旧键可能不存在，此时渲染器回退到 `templates.page` / `templates.post`，不会 500 |

### 12.4 后台会展示什么

「外观中心 → 主题设置」下方会列出该主题声明的全部页面模板（键、文案、模板文件与说明），
方便作者自查声明是否生效；页面与文章编辑器则以下拉框呈现同一清单。

## 13. 主题可用的全部 Hook 点（清单）

主题本身**不执行服务端代码**，因此它的"扩展点"就是它**能被注入/能读取**的全部位置。
逐项核对下面这张表，即可确认没有遗漏：

| 类别 | 完整清单 | 文档位置 |
| --- | --- | --- |
| 模板文件 | `templates/*.njk` + `partials/`（可任意组织，被 `extends` / `include` 复用） | §1 |
| 清单字段 | `schemaVersion`、`id`、`name`、`description`、`version`、`apiVersion`、`engine`、`author`、`license`、`screenshot`、`templates`、`pageTemplates`、`requires`、`settings` | §2 |
| 页面类型（kind） | `home`、`post`、`page`、`archive`、`search`、`404`（插件还可自定义 kind） | §2、§12 |
| 模板上下文变量 | `site`、`page`、`theme`、`viewer`、`post`、`posts`、`content`、`pagination`、`seoDescription` + 插件 `data` 的全部键 | §3 |
| Helper | `theme_asset`、`url`、`slot`、`has_feature`、`site_url` | §4 |
| 过滤器 | `css_color`、`date`、`excerpt`、`number`、`json` | §5 |
| 标准插槽 | `head.end`、`body.start`、`body.end`、`header.navigation`、`sidebar.widgets`、`post.beforeContent`、`post.afterContent`、`post.comments`、`footer.widgets` | §6 |
| 设置字段类型 | `text`、`textarea`、`color`、`boolean`、`number`、`select`、`image`、`url`、`stringList` | §2 |
| 设置字段属性 | `type`、`label`、`description`、`default`、`min`、`max`、`maxLength`、`maxItems`、`placeholder`、`options[]` | §2 |
| 多语言文案位置 | `settings.*.label`、`settings.*.description`、字段的 `label` / `description` / `placeholder`、`options[].label`、`pageTemplates.*.label` / `description` | §2、§12 |
| 静态资源 | `assets/**`，经 `theme_asset()` 输出 | §4 |
| 主题设置的三层模型 | 默认值 / 已发布覆盖 / 预览草稿 | §10 |
