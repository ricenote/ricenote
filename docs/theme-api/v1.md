# RiceNote Theme API v1

> 面向主题作者。你只需要 **HTML + CSS +（可选）Nunjucks 语法**，不需要 npm、打包器或 Node.js。

## 1. 主题包结构

```
themes/minimal/
├── theme.json              # 必需：主题清单
├── screenshot.png          # 可选：后台预览图
├── templates/
│   ├── layout.njk          # 布局（被其他模板 extends）
│   ├── index.njk           # 首页
│   ├── post.njk            # 文章详情
│   ├── archive.njk         # 归档 / 分类列表
│   ├── search.njk          # 搜索
│   ├── 404.njk             # 404
│   └── partials/
│       ├── header.njk
│       ├── footer.njk
│       └── pagination.njk
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── images/
```

安装方式：后台「外观 → 主题 → 上传 ZIP」，或直接把目录放到 `THEMES_DIR` 下。

## 2. theme.json 契约

由 `packages/shared/manifests/theme.schema.json` 校验。

```json
{
  "schemaVersion": 1,
  "id": "rice.minimal",
  "name": "Minimal",
  "version": "1.0.0",
  "apiVersion": "^1.0.0",
  "engine": "nunjucks",
  "screenshot": "./screenshot.png",
  "templates": {
    "home": "index.njk",
    "post": "post.njk",
    "archive": "archive.njk",
    "search": "search.njk",
    "404": "404.njk"
  },
  "requires": { "content.posts@1": "^1.0.0" },
  "settings": {
    "appearance": {
      "label": "外观",
      "fields": {
        "accentColor": { "type": "color", "label": "强调色", "default": "#89A9C7" },
        "showSidebar": { "type": "boolean", "label": "显示侧边栏", "default": true },
        "layoutWidth": { "type": "number", "label": "内容宽度(px)", "default": 960, "min": 640, "max": 1440 },
        "fontFamily": {
          "type": "select",
          "label": "字体",
          "default": "system",
          "options": [
            { "label": "系统", "value": "system" },
            { "label": "衬线", "value": "serif" }
          ]
        }
      }
    },
    "footer": {
      "label": "页脚",
      "fields": {
        "footerText": { "type": "text", "label": "页脚文字", "default": "Powered by RiceNote", "maxLength": 160 }
      }
    }
  }
}
```

### 模板映射

`templates` 的键是**页面类型（kind）**，由提供页面的插件决定。Core 内置约定的 kind：

| kind | 场景 | 是否必需 |
| --- | --- | --- |
| `home` | 首页 | 必需 |
| `post` | 文章详情 | 建议 |
| `archive` | 归档 / 分类 / 标签列表 | 可选 |
| `search` | 搜索结果 | 可选 |
| `404` | 未找到 | 建议 |

### 设置字段类型白名单

| 类型 | 说明 | 附加约束 |
| --- | --- | --- |
| `text` | 单行文本 | `maxLength` |
| `textarea` | 多行文本 | `maxLength` |
| `color` | 颜色 | 自动经 `css_color` 白名单校验 |
| `boolean` | 开关 | `default` 必须为布尔 |
| `number` | 数值 | `min` / `max` |
| `select` | 下拉 | 必须提供 `options` |
| `image` | 图片 | 打开媒体库，保存 Media ID 或受管相对路径 |
| `url` | 链接 | 必须以 `http://` 或 `https://` 开头 |

> `image` 类型**不允许**保存任意服务器文件路径，这是硬性安全约束。

## 3. 模板上下文

| 变量 | 可用页面 | 说明 |
| --- | --- | --- |
| `site` | 全部 | `site.title` / `site.description` / `site.url` / `site.language` |
| `page` | 全部 | `page.kind` / `page.title` / `page.canonicalUrl` |
| `theme` | 全部 | `theme.id` / `theme.name` / `theme.version` / `theme.settings.*` |
| `viewer` | 可选 | 仅暴露 `{ id, name }` |
| `post` | 文章页 | `post.title` / `post.html` / `post.terms` / `post.url` |
| `posts` | 列表页 | `posts.items` / `posts.total` / `posts.page` / `posts.totalPages` |
| `pagination` | 列表页 | `pagination.hasPrev` / `hasNext` / `prevUrl` / `nextUrl` |

> `theme.settings` 是**扁平化字段名 → 值**的映射，字段名在整个主题范围内必须唯一。

## 4. Helper

| Helper | 用法 | 说明 |
| --- | --- | --- |
| `theme_asset` | `{{ theme_asset('css/style.css') }}` | 输出带指纹的静态资源 URL |
| `url` | `{{ url('post.show', { slug: post.slug }) }}` | 基于已注册命名路由生成 URL |
| `slot` | `{{ slot('post.comments', { postId: post.id }) }}` | 输出该插槽的安全 HTML 片段 |
| `has_feature` | `{% if has_feature('comments') %}` | 判断能力当前是否实际启用 |

## 5. 过滤器

| 过滤器 | 用法 | 说明 |
| --- | --- | --- |
| `css_color` | `{{ theme.settings.accentColor \| css_color }}` | 严格白名单校验 CSS 颜色，非法值回退 `transparent` |
| `date` | `{{ post.publishedAt \| date('YYYY-MM-DD') }}` | 支持 `YYYY/MM/DD/HH/mm/ss` |
| `excerpt` | `{{ post.html \| excerpt(120) }}` | 剥离 HTML、压缩空白后截断 |
| `number` | `{{ count \| number }}` | 非法数字回退为 0，避免输出 `NaN` |

## 6. 标准 Slot

| Slot | 位置 |
| --- | --- |
| `head.end` | `</head>` 之前 |
| `body.start` / `body.end` | `<body>` 起始 / 结束 |
| `header.navigation` | 主导航区域 |
| `sidebar.widgets` | 侧边栏 |
| `post.beforeContent` / `post.afterContent` | 正文前后 |
| `post.comments` | 评论区 |
| `footer.widgets` | 页脚 |

Slot 内组件由插件提供，按 `priority` 排序；单个组件异常会被隔离并降级为空片段，
**不会**导致整页渲染失败。插件被禁用时对应 Slot 自动为空。

## 7. 完整模板示例

```html
{# templates/layout.njk #}
<!doctype html>
<html lang="{{ site.language }}">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width,initial-scale=1">
  <title>{% block title %}{{ page.title }} · {{ site.title }}{% endblock %}</title>
  <link rel="stylesheet" href="{{ theme_asset('css/style.css') }}">
  {{ slot('head.end') }}
</head>
<body style="--accent: {{ theme.settings.accentColor | css_color }}; --width: {{ theme.settings.layoutWidth | number(960) }}px">
  <header class="site-header">
    <a href="{{ url('home') }}">{{ site.title }}</a>
    {{ slot('header.navigation') }}
  </header>

  <main>{% block content %}{% endblock %}</main>

  <footer class="site-footer">
    <p>{{ theme.settings.footerText }}</p>
    {{ slot('footer.widgets') }}
    {{ slot('body.end') }}
  </footer>
</body>
</html>
```

```html
{# templates/post.njk #}
{% extends "layout.njk" %}

{% block content %}
<article class="post">
  <h1>{{ post.title }}</h1>
  <time datetime="{{ post.publishedAt }}">{{ post.publishedAt | date('YYYY年MM月DD日') }}</time>
  <ul class="terms">
    {% for term in post.terms %}<li><a href="{{ url('term.archive', { slug: term.slug }) }}">{{ term.name }}</a></li>{% endfor %}
  </ul>

  {{ slot('post.beforeContent', { postId: post.id }) }}
  <div class="post-body">{{ post.html }}</div>
  {{ slot('post.afterContent', { postId: post.id }) }}

  {% if has_feature('comments') %}{{ slot('post.comments', { postId: post.id }) }}{% endif %}
</article>
{% endblock %}
```

## 8. 模板回退链

```
主题声明的模板（如 post.njk）
  → 主题内的 fallback.njk（若存在）
  → Core 内置兼容模板
```

因此：缺少某个 kind 的模板不会导致白屏，而是降级渲染并记录告警。

## 9. 安全与限制

- **禁止**主题访问数据库或调用任意服务器端代码；
- **禁止**主题注册或修改 `/admin`、`/api` 核心路由；
- HTML 默认自动转义；文章正文由插件提供**已消毒**并标记为 `TrustedHtml` 的内容；
- 主题设置中的颜色必须经 `css_color` 过滤器输出，**不得**直接插入任意字符串；
- Nunjucks **不是安全沙箱**，只允许管理员安装受信任主题；
- ZIP 安装会校验解压大小限额、Zip Slip 路径穿越与符号链接，路径归一化后才落盘。

## 10. 设置的三层模型

```
effective = defaults + publishedOverrides                 // 公众站点
preview   = defaults + publishedOverrides + draftOverrides // 后台预览（iframe）
```

- 后台「保存并发布」会原子提交整组设置，并使用 `revision` 乐观锁；版本不一致返回 `409`。
- 「恢复默认」只影响草稿，发布需再次确认。
- 「导出」不会包含 `secret` / `token` / `password` / `key` 结尾的字段。

## 11. 版本兼容策略

- `apiVersion` 使用 semver 区间；`engine` 目前仅支持 `nunjucks`。
- 模板上下文与 helper 在 v1 内保持向后兼容；新增 helper 属于向前兼容变更。
- 主题通过 `requires` 声明依赖的插件能力；能力缺失时后台会给出降级提示，
  `has_feature()` 返回 `false`，Slot 自动为空。
